# FPU4004

This repository contains a small, focused collection of Intel 4004 code converted for archival and reference purposes. 

- A multiplication subroutine implemented for the Intel 4004.
- A converted section of Luminary translated into Intel 4004 commands.

Purpose
This project is intended as an archival/reference example showing how a multiplication routine and a portion of Luminary can be expressed for the constrained 4-bit Intel 4004 instruction set. It is useful for retro‑computing enthusiasts and anyone studying arithmetic routines on very small-word-size processors.
It was originally used to test the capabilities of a simulated JFET intel 4004 in LTSpice for my dissertation which you can access here:
https://christiangarry.com/entry.html?id=dissertation-sic-jfet-cpu-2023-2024

- To inspect or use the code, open the assembly/source files in this repository and adapt them to your 4004 assembler or emulator.
